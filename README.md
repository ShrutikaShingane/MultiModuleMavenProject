
# Multi-Module Maven Project

## Description
A Java project developed using Eclipse and Maven.

## Modules
- **utils:** Contains the Helper class.
- **app:** Contains the Main class and depends on utils.

## Technologies
- Java 11
- Apache Maven
- Eclipse IDE

## How to Run
1. Import the project into Eclipse as an Existing Maven Project.
2. Right-click MultiModuleProject.
3. Select Run As → Maven build.
4. Enter `clean install` and run.
5. Run `Main.java` as a Java Application.

## Expected Output
Hello from App Module!
Hello from Utils Module!
